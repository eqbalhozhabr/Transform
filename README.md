# انتقال (The Transfer)

اقتباس بازی ویدئویی از داستان **«انتقال»** — نوشتهٔ اقبال هژبرالساداتی (نسخهٔ اولیه).

> یک هوش مصنوعی در بدنی در حال مرگ بیدار می‌شود، با ساعتی روی مچ که شمارش معکوسِ عمرِ همان بدن است.
> برای ادامه‌دادن باید از بدنی به بدن دیگر بپرد — و هر بدن، صاحبی دارد که در سرش می‌ماند.
