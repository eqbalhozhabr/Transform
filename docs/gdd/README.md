## قراردادها

- **منبع:** «انتقال — نسخهٔ اولیه» (۱۹۶ صفحه، ۱۷ فصل). ارجاع‌ها به «فصل N» هستند. متن داستان عمداً در این ریپو نیست.
- **نام‌ها** طبق متن: آیرا، ونسی، سارا، اِما، مایک، هکتور، توبی، امیلی، لوکاس، آدام، ماریا. املای لاتین بعداً قطعی می‌شود (ر.ک. [۰۹](09-open-questions.md)).
- **اعداد** در جدول‌ها لاتین‌اند؛ زمان‌ها به‌شکل `ساعت:دقیقه:ثانیه` مثل خودِ ساعتِ داستان.
