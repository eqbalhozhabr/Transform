## قراردادها

- **منبع:** «انتقال — نسخهٔ اولیه» (۱۹۶ صفحه، ۱۷ فصل). ارجاع‌ها به «فصل N» هستند. متن داستان عمداً در این ریپو نیست.
- **نام‌ها** طبق متن: آیرا، ونسی، سارا، اِما، مایک، هکتور، توبی، امیلی، لوکاس، آدام، ماریا. املای لاتین بعداً قطعی می‌شود (ر.ک. [۰۹](09-open-questions.md)).
- **اعداد** در جدول‌ها لاتین‌اند؛ زمان‌ها به‌شکل `ساعت:دقیقه:ثانیه` مثل خودِ ساعتِ داستان.

## واژه‌نامه (ثابت در کل سند)

| فارسی | انگلیسی | معنا |
|---|---|---|
| ساعت | Clock | شمارش معکوسِ روی مچ؛ عمرِ باقی‌ماندهٔ آیرا در میزبان فعلی |
| میزبان | Host | بدنی که آیرا در آن است |
| قانونِ بدن | Host Ruleset | مجموعهٔ فعل‌ها/قیدها/ادراکِ مخصوص یک میزبان |
| پژواک | Echo | بازماندهٔ عصبی–عاطفیِ میزبان که در سر آیرا می‌ماند |
| گروه‌کر | Choir | مجموعهٔ همهٔ پژواک‌ها |
| انتقال | Transfer | جابه‌جایی چیپ از یک گردن به گردن دیگر |
| بوت | Boot | لحظهٔ بیدارشدن در میزبان جدید |
| تعقیب | Heat | میزانِ نزدیک‌شدنِ لوکاس |
| حالت کوری | Blind Mode | وضعیتی که ساعت در دسترس نیست |
